How I built a company-wide RAG Slack bot with n8n and Qdrant

Oct 21, 2026

People at CodersBucket kept asking the same questions in Slack. So I built CB Agent, a Slack bot that answers from company docs. Today all employees use it.

n8n runs the flow, Qdrant stores the docs as vectors, and Gemini answers only from what retrieval finds.

const hits = await qdrant.search("cb_docs", {
  vector: await embed(question),
  limit: 5,
});

What helped most

Small chunks, logging every question, and fixing the docs instead of the prompt.
