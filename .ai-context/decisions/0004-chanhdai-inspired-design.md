# 0004. chanhdai-inspired design

## Status

Accepted

## Context

The approved mockup (concept-b-v8) follows a dense, technical, document-like layout inspired by chanhdai.com: 768px column, hairline rules, hatch separators, dot grid.

## Decision

Reproduce that layout in CSS utilities (`screen-line-*`, `hatch-sep`, `dot-grid`, panel section titles). Keep MIT attribution for adapted utilities. Do **not** copy chanhdai branding, copy, or logo.

## Consequences

- Visual fidelity to the mockup is the acceptance bar.
- `LICENSE` credits Chánh Đại for the adapted layout utilities.
